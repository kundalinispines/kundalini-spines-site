# Spine UI V2 — Mockup Catalog

## 00 — Master Concept
**File:** `../mockups/concept-a/00-master-concept.png`

Primary reference for the visual language.

Use it for:
- anatomical wireframe spine treatment
- centered navigation axis
- rigid connector geometry
- modular node/card relationship
- main-card hierarchy
- restrained technical/occult presentation

Do not treat the black board background or placeholder copy as production requirements.

## 00b — Alternate Layout Study
**File:** `../mockups/concept-a/00b-alternate-layout-study.png`

Secondary compositional study. Useful for:
- asymmetrical card placement
- simplified connector routing
- considering large content destinations alongside the spine

The Master Concept remains the primary visual reference.

## 02 — Hover / Pre-Focus
**File:** `../mockups/states/02-hover-prefocus.png`

Shows a node preparing for activation:
- node glow increases
- restrained pulse/ripple appears
- connector paths preview partially
- target content remains ghosted or subdued
- subtle energy concentrates near the target vertebra

## 03 — Card Activation
**File:** `../mockups/states/03-card-activation.png`

Shows a standard card-node activation sequence:
- node locks active
- rigid connectors draw outward
- main card emerges from the active node
- ghost frames imply scale/depth/motion
- surrounding destinations remain secondary

For Music and Archive, borrow the same activation language but transition into an immersive destination rather than a small card.

## 05 — Node Transition
**File:** `../mockups/states/05-node-transition.png`

Shows focus transfer:
- current card recedes
- old connector releases/fades
- energy appears to travel through the spine
- new node becomes the target
- new connector draws
- new content enters

This state is important because the spine should visually explain navigation rather than merely decorate it.
