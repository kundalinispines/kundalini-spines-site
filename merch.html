Merchandise

The Objects

A lyric can become an artifact. An album image can become a symbol. A symbol can become an object you carry.

The merchandise line is the physical end of the same archive. Garments, prints, pressings and marks, built to the standard everything else here is built to — black, restrained, and marked only where a mark carries weight. Nothing decorative. Nothing that would not survive the archive.

None of it is open. There is no store, no price list, and no order to place. What follows is the catalogue as it currently stands: four categories, filed, waiting on a production run and on a decision about how anything here is sold.

Status

STANDBY. The line is documented and not yet open. This page will state a date when there is one, and nothing before then.

The Standard

An Object Has to Earn the Mark

Kundalini Spines is being built as a unified world in which music, writing, artwork, video, web design, physical objects and interactive experiences belong to the same mythology. An object made for it is held to the same rule as a bar or an image: every symbol carries weight, or it does not appear.

Restraint over noise. Structure over spectacle. Small runs, made once. Nothing is added to this catalogue to fill it out.

The archive is where the recovered material is kept. This page is where some of it becomes something you can hold.
